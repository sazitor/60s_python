# YouTube 予約アップロード

「投稿用テキスト」（タイトルと概要欄を投稿順にまとめたファイル）を読み込み、
動画を **1日1本ずつ予約投稿** でまとめてアップロードするスクリプトです。

- 公開日時は「非公開＋公開予約（publishAt）」で設定するので、公開までは誰にも見えません
- アップロード済みの動画は `uploaded.json` に記録され、もう一度実行しても二重投稿されません
- タイトル100文字・概要欄5000文字・山かっこ（< >）の有無を、アップロード前にチェックします

## フォルダの準備

動画と投稿用テキストを同じフォルダに置きます。動画のファイル名は「タイトル.mp4」です（生成した動画はそのままでOK）。

```
動画フォルダ/
├── 投稿用テキスト_10本.txt
├── 【1分でわかる】Pythonのif文入門｜elifで3つ以上に分ける！ #Python.mp4
├── 【60秒】Pythonでおみくじ作ってみた｜たった12行 #Python.mp4
└── …
```

## 最初の1回だけの準備（15分ほど）

### 1. ライブラリを入れる

```
py -m pip install -r requirements.txt
```

（Mac の場合は `py` を `python3` に読み替えてください）

### 2. Google Cloud で API を有効にする

1. https://console.cloud.google.com/ を開き、新しいプロジェクトを作る（名前は「youtube-uploader」など）
2. 「APIとサービス」→「ライブラリ」で **YouTube Data API v3** を検索して「有効にする」
3. 「APIとサービス」→「OAuth 同意画面」
   - ユーザーの種類：**外部**
   - アプリ名・メールアドレスを入力して保存
   - 「テストユーザー」に自分の Google アカウントを追加
   - 最後に **「アプリを公開」で本番環境に切り替える**（テストのままだとログインが7日で切れます）
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
   - アプリケーションの種類：**デスクトップ アプリ**
   - 作成後「JSON をダウンロード」し、名前を **`client_secret.json`** に変えて、このフォルダ（`tools/uploader/`）に置く

> `client_secret.json` と、初回ログイン後にできる `token.json` は **あなたのアカウントの鍵** です。
> 人に渡したり GitHub に上げたりしないでください（`.gitignore` で除外済み）。

## 使い方

### まず予定を確認（アップロードはしない）

```
py upload_youtube.py --plan "動画フォルダ/投稿用テキスト_10本.txt" --start "2026-10-21 18:00" --dry-run
```

公開予定の一覧が表示されます。ファイルが見つからない・日時が過去、などの問題もここでわかります。

### 本番

```
py upload_youtube.py --plan "動画フォルダ/投稿用テキスト_10本.txt" --start "2026-10-21 18:00"
```

- 初回はブラウザが開くので、動画を投稿する YouTube アカウントでログインして許可します
- 「このアプリは Google で確認されていません」と出たら「詳細」→「（アプリ名）に移動」で進めます（自分で作ったアプリなので問題ありません）

### オプション

| オプション | 意味 | 例 |
|---|---|---|
| `--start` | 1本目の公開日時（日本時間） | `"2026-10-21 18:00"` |
| `--interval-hours` | 公開の間隔（時間）。初期値 24 = 1日1本 | `12`（1日2本） |
| `--limit` | 今回アップロードする最大本数 | `1`（お試しで1本だけ） |
| `--videos` | 動画フォルダ（投稿用テキストと別の場所にある場合） | `"D:/videos"` |
| `--dry-run` | 予定の表示だけ | |

**はじめは `--limit 1` で1本だけ試し、YouTube Studio で予約が正しく入っているか確認するのがおすすめです。**
同じコマンドをもう一度実行すれば、残りの動画が続きからアップロードされます。

## アップロード後に手作業でやること

- Shorts の「関連動画」（制作回 → ペアの基礎回）の設定は、YouTube Studio で行ってください
- 公開日時を変えたいときは、YouTube Studio の「公開設定」から変更できます

## 制限

- YouTube Data API のアップロードは 1日100回まで（2026年10月時点の公式ドキュメント）
